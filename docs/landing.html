AGENT ACCESS

Give an AI system cited public-data context.

Add this to Claude Desktop, Cursor, Cline, or any MCP client:

{
  "mcpServers": {
    "datapulse-my": {
      "transport": "streamable-http",
      "url": "https://mcp.data-pulse.my/mcp"
    }
  }
}

Read-only, cited public-data context. No auth. Streamable HTTP.

  • search_datasets(query, licence?, source?)Find datasets by topic, agency, or licence and return ranked matches.
  • get_dataset(dataset_id)Return full detail, latest health, and provenance signals for one dataset.
  • find_stale(max_age_hours?)Find datasets with a freshness or schema-validity risk.
  • find_anomalies(limit?, mode?, min_reliability?)Identify unusual dataset update delays with pipeline-computed evidence.
  • find_deteriorating(limit?, min_anomaly_rate?)Find published freshness trends that are deteriorating.
  • find_recovering(limit?)Find published freshness trends that are recovering.
  • find_unreliable(limit?, at_or_below_grade?)Find datasets with low publish-reliability grades.
  • find_schema_drift(limit?, min_change_count?)Find published structural or record-count drift evidence.
  • check_reconciliation(dataset_name)Return cross-source publication differences for human review.
  • get_provenance(dataset_ids[])Return citation-ready metadata with source steward, licence, and source URL.
  • get_evidence(dataset_id)Expose the complete pipeline-published evidence receipt.
  • verify_evidence(dataset_id)Perform a cached, ephemeral transport-only live check.
  • find_by_licence(licence)Enumerate what is available under a given licence for reuse scoping.

How DataPulse complements public-data work

  • Complements the official publisher.DataPulse MY links back to public sources and documents observed evidence; it does not replace the publisher, which remains the source of record.
  • Stays read-only.It is not a data warehouse or upstream mutation layer. Public-source signals are presented for review, correction, documentation, and reuse.
  • Supports stewardship, not rankings.It does not rank agencies or make compliance judgements. Maintainers can suggest a cadence correction, exclusion, access-method correction, licence clarification, or removal through the public issue path; DataPulse documents the evidence and keeps the publisher as source of record.
