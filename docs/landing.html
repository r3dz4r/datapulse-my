{
  "mcpServers": {
    "datapulse-my": {
      "transport": "streamable-http",

    }
  }

Eleven tools. No auth. Read-only. Streamable HTTP.

  • search_datasets(query, licence?, source?)Find datasets by topic, agency, or licence and return ranked matches.
  • get_dataset(dataset_id)Return full detail, latest health, and provenance signals for one dataset.
  • find_stale(max_age_hours?)Find datasets with a freshness or schema-validity risk.
  • find_anomalies(limit?, mode?, min_reliability?)Identify unusual dataset update delays with pipeline-computed evidence.
  • find_deteriorating(limit?, min_anomaly_rate?)Find published freshness trends that are deteriorating.
  • find_recovering(limit?)Find published freshness trends that are recovering.
  • find_unreliable(limit?, at_or_below_grade?)Find datasets with low publish-reliability grades.
  • find_schema_drift(limit?, min_change_count?)Find published structural or record-count drift evidence.
  • check_reconciliation(dataset_name)Return cross-source publication differences for human review.
  • get_provenance(dataset_ids[])Return citation-ready metadata with source steward, licence, and source URL.
  • find_by_licence(licence)Enumerate what is available under a given licence for reuse scoping.

Three things this is not

  • Not a data warehouse.DataPulse MY is a trust layer. The actual data lives upstream (data.gov.my, BNM, and others). We watch it, score it, and answer “is this safe to use right now?”
  • Not authenticated.Every surface is read-only and anonymous. Push data? Fork the repo.
  • Not optimistic.About 60% of the catalogue is past its freshness window. We’d rather tell you than hide it.
