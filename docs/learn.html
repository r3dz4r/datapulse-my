MCP QUICKSTART

Connect to published context with a read-only endpoint.

This is a starter configuration for clients that use an mcpServers URL shape; client configuration varies. The endpoint provides read-only DataPulse context, not upstream writes or a browser session.

{
  "mcpServers": {
    "datapulse-my": {
      "url": "https://mcp.data-pulse.my/mcp"
    }
  }
}

CLAIM BOUNDARY

What not to claim

Do not describe the result as universally current, complete, or fit for every purpose. State the report’s observed evidence and limitations, and defer to the official source for the record itself.
