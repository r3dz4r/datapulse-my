The data.gov.my gateway aggregates GTFS feeds from KTMB, Prasarana, and APAD. Realtime endpoints are protobuf vehicle-position messages and should normally move on a 30-second cadence; Schedule endpoints are ZIP archives whose publishing cadence is daily or less frequent. A valid realtime feed with zero vehicles during 0100–0500 MYT is an off-peak observation, not a degraded source.

Treat the discontinued Kuantan static line differently from a transport or parser failure: it is an expected `status=discontinued` historical record, with no replacement ZIP to retry. For static feeds, use file modification time as the primary publication clue when `calendar.txt` service dates do not reflect the actual publication window.
