BNM operates the apikijangportal Open API and a data.gov.my mirror. The API is directly probeable: HTTP success establishes availability only, while the row date establishes content freshness. `bnm_base_rate` is a dormant reference series by design; do not reinterpret its stale health status as an endpoint outage. The live-cycle series include different cadences, including four daily `bnm_kl_usd_myr` snapshots at 0900, 1130, 1200, and 1700 MYT.

When HTTP 200 carries old JSON, read `content_date` before drawing an operational conclusion. The current BNM probe rule therefore preserves `status=stale` for the dormant reference and for cadence-lagging live-cycle series, even though the transport response is healthy.
