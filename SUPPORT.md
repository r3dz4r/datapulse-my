# Support

Use the repository's GitHub issue forms:

- Dataset metadata, freshness, schema, count, or broken report: open a bug or
  freshness-check issue and include the dataset ID plus observation time.
- Upstream source outage: file a freshness-check issue after confirming the
  official URL; DataPulse MY cannot restore an upstream publisher.
- New dataset: use the new-dataset/adopt-a-dataset form with source and licence
  evidence.
- MCP, JSON-LD, agent discovery, or integration questions: use the question
  form and include the client, transport, response code, and redacted logs.
- Sensitive security issue: follow `SECURITY.md`, not a public issue.

DataPulse MY provides metadata and monitoring on a best-effort basis. Dataset
owners remain responsible for authoritative content and availability.
